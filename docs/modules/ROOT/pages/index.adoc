= Chrysopoeia

_chrysopoeia (from Ancient Greek χρυσοποιία (khrusopoiía) 'gold-making')_

A controller creating CRDs from Helm charts by translating their `values.yaml`.
Every change to the instances from the created CRDs is preserved in an `ClaimRevision`.

The most recent approved revision is deployed using FluxCDs https://fluxcd.io/flux/components/helm/[Helm controller].
